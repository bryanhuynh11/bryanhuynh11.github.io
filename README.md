# bryanhuynh11.github.io

Personal portfolio of Bryan Huynh — CS @ UW Tacoma, building AI/ML and quant tools for financial markets.

Live: https://bryanhuynh11.github.io/?v=2

- `index.html` – page structure
- `styles.css` – design
- `script.js` – low-poly canvas background, typewriter, rendering, easter egg
- `content.js` – **all editable content** (artifact cards, projects, experience)
- `NOTES.md` – build log for TCSS 490 Artifact 1

Plain static files: open `index.html` locally or push to `main` and GitHub Pages serves it.
